# deepMD_all_repositories

DeePMD-kit 相關儲存庫索引。

本儲存庫彙整所有與 DeePMD-kit 訓練相關的程式碼和資料，作為參考索引使用。

---

## 程式功能說明

本 repo 作為索引/容器，指向其他 DeepMD 相關 repo：

| 儲存庫 | 用途 |
|---|---|
| [dp_train_new](https://github.com/jushinpon/dp_train_new) | 新版 DLP 訓練流程 |
| [dp_train_label](https://github.com/jushinpon/dp_train_label) | 標籤數據生成工具 |
| [UMA4DLP](https://github.com/jushinpon/UMA4DLP) | Unified Materials Archive |
| [dp_train](https://github.com/jushinpon/dp_train) | 原版 DLP 訓練 |
| [dpgen_preprocessor](https://github.com/jushinpon/dpgen_preprocessor) | DP-Gen 數據預處理 |
| [final_dpa_training](https://github.com/jushinpon/final_dpa_training) | 最終 DPA 訓練 |
| [DeePMD-kit-npyTools](https://github.com/jushinpon/DeePMD-kit-npyTools) | npy 工具集 |
| [dpmd_PerlScript](https://github.com/jushinpon/dpmd_PerlScript) | DeepMD-Kit LAMMPS 腳本 |
